# 验证短信登录按钮显示

## 1. 打开浏览器开发者工具（F12）

### 检查 Network 标签
1. 刷新页面
2. 找到 `/api/status` 请求
3. 查看响应内容，确认包含：
```json
{
  "sms_login_enabled": true,
  "sms_bind_enabled": true,
  "sms_reset_enabled": true,
  "register_enabled": true
}
```

### 检查 Console 标签
1. 查看是否有 JavaScript 错误
2. 输入以下命令检查状态：
```javascript
// 检查状态对象
console.log(window.localStorage.getItem('status'));
```

## 2. 检查登录页面

访问 `http://localhost:3000/login`，应该看到：

- ✅ "使用 邮箱或用户名 登录" 按钮
- ✅ **"使用 手机号 登录" 按钮**（带手机图标）
- ✅ GitHub/Discord 等 OAuth 登录按钮

## 3. 测试短信登录功能

1. 点击 "使用 手机号 登录" 按钮
2. 弹出短信登录模态框
3. 输入11位手机号（如：13800138000）
4. 点击 "获取验证码" 按钮
5. 查看是否有错误提示

## 4. 如果按钮仍然不显示

### 检查前端状态管理

打开浏览器控制台，执行：

```javascript
// 方法1：检查 React DevTools
// 安装 React DevTools 扩展后，在 Components 标签中找到 LoginForm 组件
// 查看 status.sms_login_enabled 的值

// 方法2：直接在控制台获取状态
fetch('/api/status')
  .then(res => res.json())
  .then(data => {
    console.log('SMS Login Enabled:', data.data.sms_login_enabled);
    console.log('SMS Bind Enabled:', data.data.sms_bind_enabled);
    console.log('Register Enabled:', data.data.register_enabled);
  });
```

### 检查前端代码是否部署

```bash
# 在项目根目录执行
cd web/dist
grep -r "使用 手机号 登录" .

# 如果找到匹配，说明代码已正确构建
```

## 5. 常见问题

### 问题1：按钮仍不显示
- **原因**：StatusContext 缓存问题
- **解决**：完全关闭浏览器，重新打开

### 问题2：点击按钮没反应
- **原因**：Modal 代码未正确部署
- **解决**：检查 `renderSmsLoginModal` 函数是否存在

### 问题3：获取验证码失败
- **原因**：后端短信服务未配置
- **解决**：配置 Aliyun SMS 或使用固定验证码模式测试

## 6. 使用固定验证码测试（推荐）

为了快速测试功能，建议先使用固定验证码模式：

```bash
# 设置固定验证码为 123456
curl -X PUT http://localhost:3000/api/option/ \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"key": "SmsCodeMin", "value": "123456"}'

curl -X PUT http://localhost:3000/api/option/ \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"key": "SmsCodeMax", "value": "123456"}'
```

这样所有验证码都是 `123456`，不需要真实的短信服务也能测试完整流程。
