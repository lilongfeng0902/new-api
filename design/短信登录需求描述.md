# 短信登录功能说明

## 概述

本文档提供了将短信发送、验证、记录以及手机号验证码登录功能。

## 核心功能分析

### 1. 短信验证码功能

#### 1.1 验证码生成与发送
- **验证码格式**：4-6位数字随机码
- **生成规则**：可配置起始和结束范围（默认1000-9999）
- **发送频率控制**：
  - 60秒内不允许重复发送同一手机号
  - 每日最多发送N次（默认不限制，可配置）
- **场景区分**：不同业务场景使用不同模板code

#### 1.2 验证码验证
- **有效期验证**：默认5分钟过期
- **一次性使用**：验证后标记为已使用
- **场景匹配**：验证时必须匹配发送时的场景

#### 1.3 频率限制规则
```go
// 频率限制配置
type SmsCodeConfig struct {
    ExpireTimes             time.Duration // 验证码过期时间，默认5分钟
    SendFrequency          time.Duration // 发送频率限制，默认60秒
    SendMaximumQuantityPerDay int        // 每日最大发送次数，默认不限制
    BeginCode              int          // 验证码起始值，默认1000
    EndCode                int          // 验证码结束值，默认9999
}
```

### 2. 手机号登录注册功能
基于短信验证码的用户认证流程：

#### 2.1 登录流程
1. 用户提交手机号
2. 后端验证手机号格式
3. 发送短信验证码
4. 用户输入验证码
5. 验证验证码有效性
6. 自动注册或登录用户
7. 返回JWT Token

#### 4.2 用户状态管理
- **待激活状态**：新注册用户首次登录后自动激活
- **禁用状态**：管理员可禁用用户账户
- **正常状态**：可正常使用系统

### 3. 核心业务逻辑实现建议

#### 3.1 验证码生成逻辑
```go
func (s *smsCodeService) generateCode() string {
    // 生成指定范围内的随机数
    code := rand.Intn(s.config.EndCode-s.config.BeginCode+1) + s.config.BeginCode
    return fmt.Sprintf("%0*d", len(strconv.Itoa(s.config.EndCode)), code)
}
```

#### 3.2 频率限制检查
```go
func (s *smsCodeService) checkSendFrequency(ctx context.Context, mobile string) error {
    // 查询最近一次发送记录
    lastCode, err := s.smsCodeRepo.GetLastByMobile(ctx, mobile, nil, nil)
    if err != nil {
        return err
    }

    if lastCode != nil {
        // 检查发送频率
        if time.Since(lastCode.CreateTime) < s.config.SendFrequency {
            return errors.New("发送过于频繁，请稍后再试")
        }

        // 检查每日发送上限
        if s.isToday(lastCode.CreateTime) &&
           lastCode.TodayIndex >= s.config.SendMaximumQuantityPerDay {
            return errors.New("今日发送次数已达上限")
        }
    }

    return nil
}
```

#### 3.3 验证码验证逻辑
```go
func (s *smsCodeService) validateSmsCode(ctx context.Context, mobile, code string, scene int) (*SmsCode, error) {
    // 查询验证码记录
    smsCode, err := s.smsCodeRepo.GetLastByMobile(ctx, mobile, &code, &scene)
    if err != nil {
        return nil, err
    }

    if smsCode == nil {
        return nil, errors.New("验证码不存在")
    }

    // 检查是否过期
    if time.Since(smsCode.CreateTime) > s.config.ExpireTimes {
        return nil, errors.New("验证码已过期")
    }

    // 检查是否已使用
    if smsCode.Used {
        return nil, errors.New("验证码已被使用")
    }

    return smsCode, nil
}
```

#### 3.4 用户自动注册逻辑
```go
func (a *authService) smsLogin(ctx context.Context, req *SmsLoginRequest) (*LoginResponse, error) {
    // 1. 验证短信验证码
    err := a.smsCodeService.UseSmsCode(ctx, &UseSmsCodeRequest{
        Mobile: req.Mobile,
        Code:   req.Code,
        Scene:  SmsSceneMemberLogin,
        UsedIP: req.ClientIP,
    })
    if err != nil {
        return nil, err
    }

    // 2. 获取或创建用户
    user, err := a.userService.GetOrCreateUserByMobile(ctx, req.Mobile, req.ClientIP, req.Terminal)
    if err != nil {
        return nil, err
    }

    // 3. 检查用户状态
    if user.Status == UserStatusDisabled {
        return nil, errors.New("账号已被禁用")
    }

    // 4. 如果是待激活状态，自动激活
    if user.Status == UserStatusPending {
        err = a.userService.UpdateUserStatus(ctx, user.ID, UserStatusNormal)
        if err != nil {
            return nil, err
        }
    }

    // 5. 更新登录信息
    err = a.userService.UpdateLoginInfo(ctx, user.ID, req.ClientIP)
    if err != nil {
        return nil, err
    }

    // 6. 生成JWT Token
    accessToken, refreshToken, err := a.generateTokens(user)
    if err != nil {
        return nil, err
    }

    return &LoginResponse{
        UserId:       user.ID,
        AccessToken:  accessToken,
        RefreshToken: refreshToken,
        ExpiresIn:    7200, // 2小时
    }, nil
}
```
