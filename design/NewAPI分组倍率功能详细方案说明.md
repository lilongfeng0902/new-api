# NewAPI系统分组倍率功能详细方案说明

## 1. 方案概述

### 1.1 需求背景
NewAPI系统需要支持对不同渠道商设置不同的倍率分组，并控制用户在创建令牌时的分组选择权限。具体需求包括：

- 为不同渠道商（如Claude、DeepSeek等）设置多级倍率分组
- 用户被分配到特定分组后，只能选择倍率高于等于该分组的选项
- 支持灵活的分组倍率配置和管理

### 1.2 方案目标
- 实现渠道商级别的倍率分组管理
- 建立分组倍率的层次关系和权限控制
- 确保用户体验的合理性和安全性
- 保持系统的扩展性和向后兼容性

### 1.3 核心配置项说明

#### 1.3.1 基础概念
- **分组倍率 (Group Ratio)**: 定义分组的倍率值，倍率越小越优惠
- **用户可用分组 (User Usable Groups)**: 系统预定义的可分配给用户的分组列表
- **分组间倍率 (Group-Group Ratio)**: 特殊用户组使用特定分组时的倍率
- **用户分组**: 用户被分配的基础分组，决定权限范围

#### 1.3.2 配置边界和依赖关系

##### 必填配置项
1. **用户可选分组**: 定义可分配给用户的分组列表
2. **分组倍率**: 为每个分组设置倍率值

##### 可选配置项
3. **分组特殊倍率**: 为特殊用户组设置优惠倍率
4. **分组特殊可用分组**: 控制用户组的可用分组范围

##### 配置顺序要求
```
用户可选分组 → 分组倍率 → 分组特殊倍率 → 分组特殊可用分组
```

##### 配置项依赖关系
- 分组倍率中的分组名必须在用户可选分组中定义
- 分组特殊倍率中的用户分组必须在用户可选分组中存在
- 分组特殊倍率中的使用分组必须在分组倍率中定义

## 2. 系统架构设计

### 2.1 核心概念

#### 分组倍率 (Group Ratio)
- 定义不同分组的倍率值
- 倍率越小表示越优惠（成本越低）
- 支持按渠道商设置不同的倍率层级

#### 用户分组 (User Group)
- 用户所属的基础分组
- 决定用户可用的最大权限范围

#### 令牌分组 (Token Group)
- 令牌实际使用的分组
- 必须在用户权限范围内

#### 可用分组过滤 (Usable Group Filter)
- 根据用户分组倍率过滤可选项
- 确保用户只能选择倍率合适的 groupings

### 2.2 数据结构与配置项

#### 2.2.1 用户可用分组 (User Usable Groups)
- **定义位置**: `setting/user_usable_group.go`
- **配置位置**: 系统设置 → 倍率设置 → 用户可选分组
- **数据类型**: JSON对象 `{分组名: 分组描述}`
- **作用**: 定义系统预设的可分配给用户的分组列表
- **默认值**:
```json
{
  "default": "默认分组",
  "vip": "vip分组"
}
```

#### 2.2.2 分组倍率 (Group Ratio)
- **定义位置**: `setting/ratio_setting/group_ratio.go`
- **配置位置**: 系统设置 → 倍率设置 → 分组倍率
- **数据类型**: JSON对象 `{分组名: 倍率值}`
- **倍率范围**: 0 < 倍率 ≤ 10
- **作用**: 定义各分组的基础倍率值
- **默认值**:
```json
{
  "default": 1,
  "vip": 1,
  "svip": 1
}
```

#### 2.2.3 分组间倍率 (Group-Group Ratio)
- **定义位置**: `setting/ratio_setting/group_ratio.go`
- **配置位置**: 系统设置 → 倍率设置 → 分组特殊倍率
- **数据类型**: JSON对象 `{用户分组: {使用分组: 倍率}}`
- **作用**: 为特定用户组设置使用特定分组时的特殊倍率
- **优先级**: 高于基础分组倍率
- **示例**:
```json
{
  "vip": {
    "claude_0.8": 0.7,
    "deepseek_0.8": 0.6
  }
}
```

#### 2.2.4 分组特殊可用分组 (Group Special Usable Group)
- **定义位置**: `setting/ratio_setting/group_ratio.go`
- **配置位置**: 系统设置 → 倍率设置 → 分组特殊可用分组
- **数据类型**: JSON对象 `{用户分组: {操作: 分组名}}`
- **操作符**:
  - `"+:分组名"`: 添加分组
  - `"-:分组名"`: 移除分组
  - `"分组名"`: 直接添加分组

#### 2.2.5 完整配置示例
```json
{
  "GroupRatio": {
    "claude_0.7": 0.7,
    "claude_0.8": 0.8,
    "claude_0.9": 0.9,
    "deepseek_0.7": 0.7,
    "deepseek_0.8": 0.8,
    "deepseek_0.9": 0.9,
    "default": 1.0
  },
  "UserUsableGroups": {
    "claude_0.7": "Claude 0.7倍率分组",
    "claude_0.8": "Claude 0.8倍率分组",
    "claude_0.9": "Claude 0.9倍率分组",
    "deepseek_0.7": "DeepSeek 0.7倍率分组",
    "deepseek_0.8": "DeepSeek 0.8倍率分组",
    "deepseek_0.9": "DeepSeek 0.9倍率分组",
    "vip": "VIP用户分组"
  },
  "GroupGroupRatio": {
    "vip": {
      "claude_0.8": 0.6,
      "deepseek_0.8": 0.6
    }
  }
}
```

## 3. 功能详细设计

### 3.1 分组倍率管理

#### 3.1.1 基础分组倍率设置
- **配置位置**: 系统设置 → 倍率设置 → 分组倍率
- **配置格式**: JSON对象，键为分组名称，值为倍率
- **命名规范**: `{渠道}_{倍率}` 格式，如 `claude_0.8`
- **倍率范围**: 0 < 倍率 ≤ 10

#### 3.1.2 特殊分组倍率设置
- **适用场景**: VIP用户使用特定分组时的特殊倍率
- **配置格式**: 嵌套JSON对象
- **优先级**: 特殊倍率 > 基础倍率

#### 3.1.3 用户可选分组配置
- **配置位置**: 系统设置 → 倍率设置 → 用户可选分组
- **配置格式**: JSON对象，键为分组名称，值为分组描述
- **作用**: 定义用户可以选择的分组选项

### 3.2 用户权限控制

#### 3.2.1 用户分组分配
- **操作位置**: 用户管理页面
- **分配规则**: 为用户选择一个基础分组
- **权限范围**: 用户只能使用倍率高于等于自己分组的选项

#### 3.2.2 可用分组过滤逻辑
```
用户分组倍率 = R_user
可用分组条件 = R_group ≤ R_user
```

其中：
- R_user: 用户所在分组的倍率
- R_group: 可选分组的倍率
- 倍率越小表示越优惠

#### 3.2.3 令牌创建限制
- 用户登录后创建令牌时
- 系统自动过滤分组选项
- 只显示用户有权限的分组

### 3.3 渠道商分组示例

#### Claude系列分组配置
```json
{
  "claude_0.7": 0.7,
  "claude_0.8": 0.8,
  "claude_0.9": 0.9
}
```

#### DeepSeek系列分组配置
```json
{
  "deepseek_0.7": 0.7,
  "deepseek_0.8": 0.8,
  "deepseek_0.9": 0.9
}
```

## 4. 配置流程

### 4.1 管理员配置流程

#### 4.1.1 配置用户可选分组（第一步）
- **页面位置**: 系统设置 → 倍率设置 → 用户可选分组
- **操作步骤**:
  1. 进入分组倍率设置页面
  2. 在"用户可选分组"文本框中输入JSON配置
  3. 定义所有可分配给用户的分组及描述
- **必填项**: 是
- **示例**:
```json
{
  "claude_0.7": "Claude 超级优惠分组 (0.7倍)",
  "claude_0.8": "Claude 优惠分组 (0.8倍)",
  "claude_0.9": "Claude 标准分组 (0.9倍)",
  "deepseek_0.7": "DeepSeek 超级优惠分组 (0.7倍)",
  "deepseek_0.8": "DeepSeek 优惠分组 (0.8倍)",
  "deepseek_0.9": "DeepSeek 标准分组 (0.9倍)",
  "vip": "VIP用户分组"
}
```

#### 4.1.2 配置分组倍率（第二步）
- **页面位置**: 系统设置 → 倍率设置 → 分组倍率
- **操作步骤**:
  1. 在"分组倍率"文本框中输入JSON配置
  2. 为每个分组设置对应的倍率值
  3. 倍率范围必须在 0-10 之间
- **必填项**: 是
- **验证规则**: 倍率必须大于0，小于等于10
- **示例**:
```json
{
  "claude_0.7": 0.7,
  "claude_0.8": 0.8,
  "claude_0.9": 0.9,
  "deepseek_0.7": 0.7,
  "deepseek_0.8": 0.8,
  "deepseek_0.9": 0.9,
  "vip": 0.8,
  "default": 1.0
}
```

#### 4.1.3 配置分组特殊倍率（可选）
- **页面位置**: 系统设置 → 倍率设置 → 分组特殊倍率
- **操作步骤**:
  1. 在"分组特殊倍率"文本框中输入JSON配置
  2. 为VIP等特殊用户组设置优惠倍率
- **必填项**: 否
- **示例**:
```json
{
  "vip": {
    "claude_0.8": 0.6,
    "deepseek_0.8": 0.6
  }
}
```

#### 4.1.4 配置分组特殊可用分组（可选）
- **页面位置**: 系统设置 → 倍率设置 → 分组特殊可用分组
- **操作步骤**:
  1. 在"分组特殊可用分组"文本框中输入JSON配置
  2. 使用操作符控制分组的可用性
- **必填项**: 否
- **操作符说明**:
  - `"+:分组名"`: 为用户组添加额外的可用分组
  - `"-:分组名"`: 从用户组中移除指定的分组
  - `"分组名"`: 直接为用户组添加分组

### 4.2 用户管理流程

#### 4.2.1 为用户分配分组
- **页面位置**: 用户管理页面 → 编辑用户
- **操作步骤**:
  1. 进入用户管理页面
  2. 选择要编辑的用户
  3. 在用户编辑表单中选择"分组"字段
  4. 从下拉列表中选择合适的分组（如 claude_0.8）
  5. 保存用户设置
- **重要说明**: 用户分组决定了该用户能使用的令牌分组范围

#### 4.2.2 VIP分组的定义
- **VIP分组来源**: 在"用户可选分组"中定义的"vip"分组
- **特殊权限**: VIP用户可以获得额外的倍率优惠
- **配置位置**: 系统设置 → 倍率设置 → 用户可选分组

### 4.3 用户使用流程

1. **用户分组分配**
   - 管理员在用户管理页面为用户分配基础分组
   - 如：用户A分配到 `claude_0.8` 分组

2. **令牌创建**
   - 用户登录系统
   - 点击创建令牌
   - 系统自动调用 `/api/pricing` 接口
   - 接口返回经过过滤的可用分组列表

3. **权限验证**
   - 用户选择分组后，系统验证权限
   - 确保选择的倍率不超过用户权限范围

## 5. 业务规则

### 5.1 倍率层次规则

| 倍率 | 含义 | 权限等级 |
|------|------|----------|
| 0.7 | 最优惠 | 最高权限 |
| 0.8 | 中等优惠 | 中等权限 |
| 0.9 | 轻微优惠 | 基础权限 |
| 1.0 | 标准价 | 普通权限 |

### 5.2 用户权限矩阵

假设用户属于 `claude_0.8` 分组：

| 分组 | 倍率 | 是否可用 | 理由 |
|------|------|----------|------|
| claude_0.7 | 0.7 | ✅ | 0.7 ≤ 0.8 |
| claude_0.8 | 0.8 | ✅ | 0.8 ≤ 0.8 |
| claude_0.9 | 0.9 | ❌ | 0.9 > 0.8 |

### 5.3 特殊规则

1. **default分组**: 倍率为1.0，所有用户默认可用
2. **VIP分组定义**: VIP分组在"用户可选分组"中定义，本身也具有倍率值
3. **权限继承**: 低倍率分组自动获得高倍率分组的权限
4. **特殊倍率**: VIP用户可获得额外的倍率优惠（通过分组间倍率配置）
5. **渠道隔离**: 不同渠道的分组相互独立
6. **配置顺序**: 必须先配置用户可选分组，再配置分组倍率

### 6.2 用户分配示例

#### 6.2.1 普通用户分配
| 用户 | 分配分组 | 分组倍率 | 可用的令牌分组 |
|------|----------|----------|----------------|

1. **用户可选分组**: 定义所有可分配的分组（包括VIP分组）
2. **分组倍率**: 为每个分组设置基础倍率
3. **分组特殊倍率**: 为VIP用户设置特殊优惠
4. **用户管理**: 在用户编辑页面选择分配分组

## 7. API接口说明

### 7.1 获取定价信息
- **接口**: `GET /api/pricing`
- **返回参数**:
  - `group_ratio`: 分组倍率配置
  - `usable_group`: 用户可用分组（已过滤）
  - `auto_groups`: 自动分组配置

### 7.2 创建令牌
- **接口**: `POST /api/token`
- **权限验证**: 系统自动验证分组权限
- **错误处理**: 无权限时返回相应错误信息
