# 阿里云短信告警功能单元测试说明

## 概述

本项目为阿里云短信告警功能提供了全面的单元测试套件，涵盖了短信发送、用户通知、额度告警和配置管理等核心功能。

## 测试文件结构

```
├── common/alisms_test.go           # 阿里云短信发送功能测试
├── service/user_notify_test.go     # 用户通知服务测试
├── service/quota_test.go           # 额度告警逻辑测试
├── model/option_test.go            # 配置管理测试
└── makefile                        # 测试运行脚本
```

## 测试覆盖的功能

### 1. 阿里云短信发送功能测试 (`common/alisms_test.go`)

#### URL编码测试 (`TestPercentEncode`)
- 测试URL编码函数对各种字符的处理
- 验证特殊字符的正确编码

#### 签名生成测试 (`TestSignStringToString`)
- 测试HMAC-SHA1签名算法的正确性
- 验证签名格式和长度

#### 查询字符串构建测试 (`TestBuildCanonicalizedQueryString`)
- 测试规范化查询字符串的构建
- 验证参数排序和编码

#### 短信发送测试 (`TestSendAliyunSMS`)
- 使用httptest创建mock服务器
- 测试成功发送和错误处理的场景
- 验证请求参数和响应处理

#### 额度告警短信测试 (`TestSendQuotaWarningSMS`)
- 测试专用额度告警短信发送功能
- 验证模板参数的正确传递

#### 性能基准测试
- `BenchmarkPercentEncode`: URL编码性能测试
- `BenchmarkBuildCanonicalizedQueryString`: 查询字符串构建性能测试

### 2. 用户通知服务测试 (`service/user_notify_test.go`)

#### SMS通知发送测试 (`TestSendSMSNotify`)
- 测试SMS通知的完整发送流程
- 验证内容占位符替换
- 测试各种错误场景

#### 空手机号测试 (`TestSendSMSNotifyEmptyPhoneNumber`)
- 测试手机号为空时的错误处理

#### 内容处理测试 (`TestSendSMSNotifyContentProcessing`)
- 验证额度信息的正确提取和传递

#### 性能基准测试 (`BenchmarkSendSMSNotify`)
- 测试SMS通知发送的性能表现

### 3. 额度告警逻辑测试 (`service/quota_test.go`)

#### 内容格式测试 (`TestSMSQuotaNotificationContentFormat`)
- 测试不同通知类型的内容格式
- 验证SMS、Email、Bark、Gotify的内容差异

#### 阈值逻辑测试 (`TestQuotaThresholdLogic`)
- 测试额度低于阈值的判断逻辑
- 验证边界条件的处理

#### 自定义阈值测试 (`TestQuotaWarningThresholdFromSettings`)
- 测试用户自定义告警阈值
- 验证系统默认值和用户设置的优先级

#### 性能基准测试 (`BenchmarkQuotaNotificationContentProcessing`)
- 测试内容处理逻辑的性能

### 4. 配置管理测试 (`model/option_test.go`)

#### 配置初始化测试 (`TestAliyunSMSConfigInitialization`)
- 验证阿里云SMS配置项的正确初始化
- 确保所有必要配置项都存在

#### 配置更新测试 (`TestAliyunSMSConfigUpdate`)
- 测试配置值的动态更新
- 验证内存中变量的正确修改

#### 无效配置测试 (`TestAliyunSMSConfigUpdateInvalidKey`)
- 测试无效配置键的处理

#### 配置映射测试 (`TestAliyunSMSConfigInOptionMap`)
- 验证配置项在选项映射中的存在性
- 确保敏感信息不被暴露

#### 性能基准测试
- `BenchmarkAliyunSMSConfigUpdate`: 配置更新性能测试
- `BenchmarkInitOptionMap`: 配置初始化性能测试

## 测试策略

### 单元测试原则
1. **隔离性**: 每个测试函数独立运行，不依赖外部状态
2. **可重复性**: 测试结果稳定，不受环境影响
3. **快速性**: 测试执行迅速，支持频繁运行

### Mock策略
- 使用Go标准库的`httptest`创建HTTP mock服务器
- 通过保存/恢复全局变量来隔离配置状态
- 避免依赖真实网络和数据库操作

### 测试数据
- 使用固定的测试数据确保结果可预测
- 覆盖正常场景和边界条件
- 包含错误场景的测试用例

## 测试覆盖率目标

- **语句覆盖率**: > 80%
- **分支覆盖率**: > 70%
- **函数覆盖率**: 100% (核心函数)

## 故障排除

### 常见问题

1. **测试失败**: 检查是否有未清理的全局状态
2. **Mock服务器问题**: 确保每个测试正确启动和关闭mock服务器
3. **依赖问题**: 测试应避免依赖外部服务，使用mock替代

### 调试技巧

1. 使用 `-v` 标志查看详细测试输出
2. 使用 `t.Logf()` 在测试中输出调试信息
3. 运行单个测试函数：`go test -run TestFunctionName`

## 集成测试

### 阿里云SMS集成测试

项目提供了阿里云SMS的集成测试功能，用于验证在真实环境中的短信发送功能。

#### 集成测试文件
- `common/alisms_integration_test.go` - 阿里云SMS集成测试

#### 运行集成测试

1. **设置环境变量**：
   ```bash
   export ALIYUN_SMS_INTEGRATION_TEST=true
   export ALIYUN_SMS_ACCESS_KEY_ID=your_access_key_id
   export ALIYUN_SMS_ACCESS_KEY_SECRET=your_access_key_secret
   export ALIYUN_SMS_SIGN_NAME=your_sms_sign
   export ALIYUN_SMS_TEMPLATE_CODE=SMS_xxxxxxxxx
   export ALIYUN_SMS_TEST_PHONE=13800000000
   ```

2. **运行集成测试**：
   ```bash
   go test -tags integration -run TestSendAliyunSMSRealIntegration -v ./common
   ```

#### 集成测试说明

集成测试包含以下测试场景：
- **发送简单短信**：测试无模板参数的短信发送
- **发送模板短信**：测试带模板参数的短信发送
- **发送额度告警短信**：测试专用额度告警功能
- **无效手机号测试**：验证错误处理
- **频率限制测试**：测试阿里云SMS的发送频率限制

#### ⚠️ 重要提醒

- 集成测试会发送**真实短信**，产生实际费用
- 确保阿里云账户有足够余额
- 短信签名和模板必须已审核通过
- 建议只在staging或测试环境运行
- 使用真实手机号进行测试

#### 环境配置检查

运行正常的单元测试时，会自动检查集成测试的环境配置：

```bash
go test -v ./common -run TestAliyunSMSIntegrationSetup
```

此检查不会发送真实短信，只是验证环境变量配置是否正确。

## 扩展测试

### 添加新测试

1. 在相应的 `_test.go` 文件中添加测试函数
2. 遵循 `TestXxx` 或 `BenchmarkXxx` 命名约定
3. 使用 `t.Run()` 创建子测试以提高可读性

### 测试新功能

为新增功能编写测试时，请考虑：
- 正常流程测试
- 边界条件测试
- 错误处理测试
- 性能测试（如果适用）
- 集成测试（如果涉及外部服务）

## 维护建议

- 定期运行测试确保功能正常
- 在修改代码后及时更新相关测试
- 保持测试代码的清晰和简洁
- 添加必要的注释说明测试意图
