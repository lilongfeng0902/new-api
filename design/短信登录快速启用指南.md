# 短信登录功能快速启用指南

## 问题说明

前端登录页面未显示短信登录按钮的原因：**后端 `/api/status` 接口未返回 SMS 相关状态字段**。

## 已修复的问题

在 `controller/misc.go` 的 `GetStatus` 函数中添加了以下字段：

```go
// SMS Login Configuration
"sms_login_enabled": common.OptionMap["SmsLoginEnabled"] == "true",
"sms_bind_enabled":  common.OptionMap["SmsBindEnabled"] == "true",
"sms_reset_enabled": common.OptionMap["SmsResetEnabled"] == "true",
"register_enabled":  common.RegisterEnabled,
```

## 快速启用步骤

### 1. 重新编译后端

```bash
# 在项目根目录执行
go build -o new-api

# 或使用 make
make build
```

### 2. 配置环境变量

在 `.env` 文件中添加或修改以下配置：

```bash
# === 短信登录基础配置 ===
SMS_LOGIN_ENABLED=true              # 启用短信登录
SMS_AUTO_REGISTER_ENABLED=true      # 允许自动注册
SMS_BIND_ENABLED=true               # 启用手机号绑定
SMS_RESET_ENABLED=true              # 启用密码重置

# === 验证码配置 ===
SMS_CODE_LENGTH=6                   # 验证码长度
SMS_CODE_MIN=100000                 # 验证码最小值
SMS_CODE_MAX=999999                 # 验证码最大值
SMS_CODE_EXPIRE_MINUTES=5           # 验证码过期时间（分钟）

# === 频率控制 ===
SMS_SEND_FREQUENCY_SECONDS=60       # 发送频率限制（秒）
SMS_MAX_SEND_PER_DAY=10             # 每日最大发送次数

# === 阿里云短信模板 ===
SMS_LOGIN_TEMPLATE_CODE=SMS_123456789   # 登录验证码模板CODE
SMS_BIND_TEMPLATE_CODE=SMS_123456790    # 绑定验证码模板CODE
SMS_RESET_TEMPLATE_CODE=SMS_123456791   # 重置密码验证码模板CODE

# === 测试环境固定验证码（可选） ===
# 设置 min=max 时发送固定验证码，便于测试
# SMS_CODE_MIN=123456
# SMS_CODE_MAX=123456
```

### 3. 配置阿里云短信服务

在 `.env` 中添加阿里云短信配置：

```bash
# 阿里云短信服务配置
ALIYUN_SMS_ENDPOINT=dysmsapi.aliyuncs.com
ALIYUN_SMS_ACCESS_KEY_ID=你的AccessKeyId
ALIYUN_SMS_ACCESS_KEY_SECRET=你的AccessKeySecret
ALIYUN_SMS_SIGN_NAME=你的短信签名
```

### 4. 启动服务

```bash
# 方式1：直接运行
./new-api

# 方式2：使用 Docker
docker-compose up -d

# 方式3：后台运行
nohup ./new-api > new-api.log 2>&1 &
```

### 5. 验证配置

#### 5.1 检查后端状态接口

```bash
# 获取系统状态
curl http://localhost:3000/api/status | jq

# 应该看到以下字段：
# {
#   "success": true,
#   "data": {
#     "sms_login_enabled": true,
#     "sms_bind_enabled": true,
#     "sms_reset_enabled": true,
#     "register_enabled": true,
#     ...
#   }
# }
```

#### 5.2 通过管理后台API配置

如果不想重启服务，可以通过API直接配置：

```bash
# 获取管理员token（先登录管理后台）
ADMIN_TOKEN="your_admin_token_here"

# 启用短信登录
curl -X PUT http://localhost:3000/api/option/ \
  -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"key": "SmsLoginEnabled", "value": "true"}'

# 启用手机号绑定
curl -X PUT http://localhost:3000/api/option/ \
  -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"key": "SmsBindEnabled", "value": "true"}'

# 设置登录模板CODE
curl -X PUT http://localhost:3000/api/option/ \
  -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"key": "SmsLoginTemplateCode", "value": "SMS_123456789"}'
```

### 6. 前端验证

#### 6.1 启动前端开发服务器

```bash
cd web
bun install
bun run dev
```

#### 6.2 检查登录页面

1. 打开浏览器访问 `http://localhost:5173/login`
2. 应该能看到以下按钮：
   - ✅ "使用 邮箱或用户名 登录"
   - ✅ "使用 手机号 登录" （新增）
   - ✅ GitHub/Discord 等 OAuth 登录按钮

#### 6.3 测试短信登录流程

1. 点击"使用 手机号 登录"按钮
2. 弹出短信登录模态框
3. 输入11位手机号（如：13800138000）
4. 点击"获取验证码"按钮
5. 观察倒计时是否正常显示（默认60秒）
6. 输入收到的验证码
7. 点击"登录"按钮
8. 验证是否成功登录

### 7. 测试手机号绑定

1. 登录后进入 **个人设置**
2. 在"账户管理"标签页下找到"手机号"卡片
3. 点击"绑定"按钮
4. 输入手机号并获取验证码
5. 输入验证码完成绑定
6. 验证手机号是否正确显示
7. 测试"修改绑定"和"解绑"功能

### 8. 测试系统设置

1. 以管理员身份登录
2. 进入 **系统设置 - 系统设置**
3. 滚动到"短信验证码登录配置"区域
4. 验证是否能看到14个配置项：
   - 启用短信登录
   - 允许自动注册
   - 启用手机号绑定
   - 启用密码重置
   - 重置密码后清除会话
   - 验证码长度
   - 验证码最小值
   - 验证码最大值
   - 验证码过期时间（分钟）
   - 发送频率限制（秒）
   - 每日最大发送次数
   - 登录验证码模板CODE
   - 绑定验证码模板CODE
   - 重置密码验证码模板CODE
5. 修改配置并保存
6. 验证配置是否立即生效（无需重启）

## 故障排查

### 问题1: 前端仍然看不到短信登录按钮

**检查步骤**：

1. **确认后端已重新编译**
   ```bash
   # 检查二进制文件修改时间
   ls -lh new-api

   # 应该是刚刚编译的时间
   ```

2. **确认后端已重启**
   ```bash
   # 检查进程
   ps aux | grep new-api

   # 停止旧进程
   pkill new-api

   # 重新启动
   ./new-api
   ```

3. **检查浏览器控制台**
   - 打开浏览器开发者工具（F12）
   - 查看 Network 标签
   - 找到 `/api/status` 请求
   - 检查响应中是否包含 `sms_login_enabled: true`

4. **清除浏览器缓存**
   ```
   Ctrl + F5 (Windows/Linux)
   Cmd + Shift + R (Mac)
   ```

### 问题2: 点击"获取验证码"没有反应

**可能原因**：

1. **阿里云短信服务未配置**
   - 检查 `.env` 中的阿里云配置
   - 验证 AccessKey 和 Secret 是否正确

2. **模板CODE未配置**
   ```bash
   # 检查配置
   curl http://localhost:3000/api/option/ \
     -H "Authorization: Bearer $ADMIN_TOKEN" | jq '.data[] | select(.key | startswith("Sms"))'
   ```

3. **频率限制**
   - 检查是否在60秒内重复请求
   - 检查是否超过每日发送上限

4. **查看后端日志**
   ```bash
   # 查看实时日志
   tail -f new-api.log

   # 查看错误日志
   grep -i error new-api.log
   ```

### 问题3: 验证码收不到

**检查步骤**：

1. **查看后端日志**
   ```bash
   grep -i "sms" new-api.log | tail -20
   ```

2. **检查阿里云账户**
   - 登录阿里云控制台
   - 检查短信服务余额
   - 查看发送记录

3. **验证手机号格式**
   - 确保是11位中国大陆手机号
   - 格式：13800138000

4. **测试固定验证码模式**
   ```bash
   # 设置固定验证码（测试用）
   curl -X PUT http://localhost:3000/api/option/ \
     -H "Authorization: Bearer $ADMIN_TOKEN" \
     -H "Content-Type: application/json" \
     -d '{"key": "SmsCodeMin", "value": "123456"}'

   curl -X PUT http://localhost:3000/api/option/ \
     -H "Authorization: Bearer $ADMIN_TOKEN" \
     -H "Content-Type: application/json" \
     -d '{"key": "SmsCodeMax", "value": "123456"}'

   # 现在所有验证码都是 123456
   ```

### 问题4: 登录成功但没有跳转

**检查**：
- 浏览器控制台是否有报错
- 检查 UserContext 是否正确更新
- 验证 localStorage 中是否保存了用户信息
