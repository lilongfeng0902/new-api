# 短信登录功能优化说明

## 更新日期
2026-01-24

## 优化概述

基于原有的短信登录功能，新增两项重要优化，提升测试便利性和管理灵活性。

---

## 优化功能1：可配置验证码范围

### 功能描述
支持通过配置限定验证码生成的最小值和最大值，当两者相等时可发送固定验证码，极大便于测试环境使用。

### 新增配置项

| 配置键 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `SmsCodeMin` | int | 100000 | 验证码最小值（6位默认100000） |
| `SmsCodeMax` | int | 999999 | 验证码最大值（6位默认999999） |

### 使用场景

#### 场景1：生产环境（随机验证码）
```bash
# .env 配置
SMS_CODE_MIN=100000
SMS_CODE_MAX=999999
```
**效果**：生成 100000-999999 范围内的随机6位验证码

#### 场景2：测试环境（固定验证码）
```bash
# .env 配置
SMS_CODE_MIN=123456
SMS_CODE_MAX=123456
```
**效果**：所有验证码固定为 `123456`，便于自动化测试

#### 场景3：特定范围验证码
```bash
# .env 配置
SMS_CODE_MIN=500000
SMS_CODE_MAX=599999
```
**效果**：生成 500000-599999 范围内的随机验证码

### 实现细节

**文件变更**：

1. **model/option.go**（新增配置项）
```go
common.OptionMap["SmsCodeMin"] = "100000"
common.OptionMap["SmsCodeMax"] = "999999"
```

2. **service/sms_code.go**（优化代码生成逻辑）
```go
type SmsCodeConfig struct {
    CodeLength           int
    CodeMin              int // 新增：最小值
    CodeMax              int // 新增：最大值
    ExpireMinutes        int
    SendFrequencySeconds int
    MaxSendPerDay        int
}

func (s *SmsCodeService) GenerateCode() string {
    minCode := s.config.CodeMin
    maxCode := s.config.CodeMax

    // 当 min == max 时，使用固定验证码
    if minCode == maxCode {
        format := fmt.Sprintf("%%0%dd", length)
        return fmt.Sprintf(format, minCode)
    }

    // 生成随机验证码
    code := rand.Intn(maxCode-minCode+1) + minCode
    format := fmt.Sprintf("%%0%dd", length)
    return fmt.Sprintf(format, code)
}
```

3. **controller/sms_login.go**（加载配置）
```go
func getSmsCodeConfig() *service.SmsCodeConfig {
    config := &service.SmsCodeConfig{
        CodeLength: 6,
        CodeMin:    100000,
        CodeMax:    999999,
        // ...
    }

    // 从数据库加载配置
    if val, _ := model.GetOptionByKey("SmsCodeMin"); val != "" {
        if min, err := strconv.Atoi(val); err == nil {
            config.CodeMin = min
        }
    }
    if val, _ := model.GetOptionByKey("SmsCodeMax"); val != "" {
        if max, err := strconv.Atoi(val); err == nil {
            config.CodeMax = max
        }
    }

    return config
}
```

4. **.env.example**（文档更新）
```bash
# 验证码最小值（当min=max时发送固定验证码，便于测试）
# SMS_CODE_MIN=100000
# 验证码最大值
# SMS_CODE_MAX=999999

# 测试环境固定验证码示例
# SMS_CODE_MIN=123456
# SMS_CODE_MAX=123456
```

### 安全保障

系统会自动校验和调整配置值：

1. **范围合法性检查**：验证码范围不能超出长度限制
   - 6位验证码：0-999999
   - 4位验证码：0-9999

2. **自动纠错**：
   - 如果 `min > max`，系统会自动交换两者
   - 如果范围超出限制，系统会自动调整为合法值

3. **生产环境警告**：
   - 建议生产环境使用随机验证码（min ≠ max）
   - 固定验证码仅用于测试和开发环境

## 优化功能2：管理后台API配置

### 功能描述
所有短信验证码相关的参数（共14个）均可通过管理后台API进行动态配置，无需修改代码或重启服务。

### API接口

#### 1. 获取所有配置
```http
GET /api/option/
Authorization: Bearer <admin_token>
```

**响应示例**：
```json

    "success": true,
    "message": "",
    "data": [

        {"key": "Smssend_frequency_seconds", "value": "60"},
        {"key": "Smsmax_send_per_day", "value": "10"},
        {"key": "Smsauto_register_enabled", "value": "true"},
        {"key": "Smslogin_template_code", "value": "SMS_123456789"},
```

### 前端集成示例

前端管理面板可以通过以下代码实现SMS配置管理：

```javascript
// 获取所有SMS配置
async function getSmsSettings() {
  const response = await fetch('/api/option/', {
    headers: {
      'Authorization': `Bearer ${adminToken}`
    }
  });
  const result = await response.json();

  // 筛选SMS相关配置
  const smsSettings = result.data.filter(item =>
    item.key.startsWith('sms_')
  );

  return smsSettings;
}

// 更新SMS配置
async function updateSmsSetting(key, value) {
  const response = await fetch('/api/option/', {
    method: 'PUT',
    headers: {
      'Authorization': `Bearer ${adminToken}`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({ key, value })
  });

  const result = await response.json();
  return result.success;
}

// 批量更新SMS配置
async function updateAllSmsSettings(settings) {
  for (const [key, value] of Object.entries(settings)) {
    await updateSmsSetting(key, value);
  }
}

// 使用示例
const newSettings = {
  SmsLoginEnabled: true,
  SmsCodeMin: 123456,
  SmsCodeMax: 123456,  // 固定验证码
  SmsCodeExpireMinutes: 10,
  SmsSendFrequencySeconds: 120
};

await updateAllSmsSettings(newSettings);
```

### 配置生效机制

1. **即时生效**：配置更新后立即写入数据库和内存缓存
2. **无需重启**：所有新的验证码请求都会使用最新配置
3. **自动同步**：配置通过 `common.OptionMap` 全局共享
4. **持久化存储**：配置保存在数据库 `options` 表中

### 可配置参数完整列表（14个）

| 参数 | 说明 | 默认值 | 建议值 |
|------|------|--------|--------|
| `SmsLoginEnabled` | 启用短信登录 | false | true |
| `SmsCodeLength` | 验证码长度 | 6 | 6 或 4 |
| `SmsCodeMin` | 验证码最小值 | 100000 | 生产：100000，测试：123456 |
| `SmsCodeMax` | 验证码最大值 | 999999 | 生产：999999，测试：123456 |
| `SmsCodeExpireMinutes` | 验证码过期时间（分钟） | 5 | 5-10 |
| `SmsSendFrequencySeconds` | 发送频率限制（秒） | 60 | 60-120 |
| `SmsMaxSendPerDay` | 每日最大发送次数 | 10 | 10-20 |
| `SmsAutoRegisterEnabled` | 允许自动注册 | true | true |
| `SmsLoginTemplateCode` | 登录验证码模板 | "" | SMS_XXXXXXX |
| `SmsBindTemplateCode` | 绑定验证码模板 | "" | SMS_YYYYYYY |
| `SmsResetTemplateCode` | 重置验证码模板 | "" | SMS_ZZZZZZZ |
| `SmsBindEnabled` | 启用手机号绑定 | true | true |
| `SmsResetEnabled` | 启用密码重置 | true | true |
| `SmsResetClearSessions` | 重置后清除会话 | false | false |

## 测试指南

### 测试场景1：固定验证码测试

**步骤**：
1. 通过API设置 `SmsCodeMin=123456`，`SmsCodeMax=123456`
2. 请求发送验证码到手机号 `13800138000`
3. 验证收到的验证码是否固定为 `123456`
4. 使用 `123456` 完成登录

**预期**：所有验证码都是 `123456`

### 测试场景2：恢复随机验证码

**步骤**：
1. 通过API设置 `SmsCodeMin=100000`，`SmsCodeMax=999999`
2. 连续请求3次发送验证码
3. 验证3次收到的验证码都不相同

**预期**：每次验证码都是 100000-999999 范围内的随机值

### 测试场景3：配置即时生效

**步骤**：
1. 设置 `SmsCodeExpireMinutes=10`
2. 立即发送验证码
3. 9分钟后使用验证码登录

**预期**：验证码仍然有效（未过期）

### 测试场景4：动态调整发送频率

**步骤**：
1. 设置 `SmsSendFrequencySeconds=30`
2. 发送验证码
3. 等待 30 秒
4. 再次发送验证码

**预期**：第二次发送成功（不提示"发送过于频繁"）
