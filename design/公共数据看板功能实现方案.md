# 公共数据看板功能实现方案

## 📋 需求概述

新增一个公开的数据看板功能，允许未登录用户查看系统整体的使用统计数据。主要要求：
- 数据来源：基于现有的指标数据表（`quota_data`）
- 用户条件：去除用户作为查询条件，返回系统全量数据
- 接口权限：无需登录认证即可访问
- 功能范围：展示系统整体统计信息和图表数据

## 🎯 实现方案

### 核心思路
直接复用现有的管理员数据看板逻辑，通过修改查询条件和权限控制来实现公开访问：
- 使用现有的 `GetAllQuotaDates` 函数，当 `username` 参数为空时查询全量数据
- 新增公开路由 `/api/data/public`，无需认证即可访问
- 前端基于返回的聚合数据进行统计和图表展示

## 🔧 后端实现

### 1. 控制器实现 (`controller/usedata.go`)

新增 `GetPublicQuotaDates` 函数：

```go
// GetPublicQuotaDates 公共数据看板接口 - 未登录用户可访问
func GetPublicQuotaDates(c *gin.Context) {
	startTimestamp, _ := strconv.ParseInt(c.Query("start_timestamp"), 10, 64)
	endTimestamp, _ := strconv.ParseInt(c.Query("end_timestamp"), 10, 64)

	// 如果没有提供时间参数，使用默认的最近7天
	if startTimestamp == 0 || endTimestamp == 0 {
		now := time.Now()
		endTimestamp = now.Unix()
		startTimestamp = now.AddDate(0, 0, -7).Unix()
	}

	// 限制查询时间范围不超过31天，防止性能问题
	if endTimestamp-startTimestamp > 31*24*3600 {
		c.JSON(http.StatusOK, gin.H{
			"success": false,
			"message": "时间跨度不能超过31天",
		})
		return
	}

	// 获取按时间和模型分组的详细数据（用于图表）
	// username为空时，GetAllQuotaDates会查询所有数据
	quotaData, err := model.GetAllQuotaDates(startTimestamp, endTimestamp, "")
	if err != nil {
		common.ApiError(c, err)
		return
	}

	c.JSON(http.StatusOK, gin.H{
		"success": true,
		"message": "",
		"data":    quotaData,
	})
	return
}
```

### 2. 路由配置 (`router/api-router.go`)

### 3. 数据模型 (`model/usedata.go`)

复用现有的 `GetAllQuotaDates` 函数，该函数已支持按用户名过滤：

```go
func GetAllQuotaDates(startTime int64, endTime int64, username string) (quotaData []*QuotaData, err error) {
	if username != "" {
		return GetQuotaDataByUsername(username, startTime, endTime)
	}
	var quotaDatas []*QuotaData
	// 从quota_data表中查询数据
	err = DB.Table("quota_data").Select("model_name, sum(count) as count, sum(quota) as quota, sum(token_used) as token_used, created_at").Where("created_at >= ? and created_at <= ?", startTime, endTime).Group("model_name, created_at").Find(&quotaDatas).Error
	return quotaDatas, err
}
```

**数据聚合逻辑：**
- 按 `model_name` 和 `created_at`（精确到小时）分组
- 计算每个分组的总 `count`、`quota`、`token_used`
- `created_at` 只精确到小时（去除分钟和秒）

## 📡 API接口说明

### 接口地址
```
GET /api/data/public
```

### 请求参数
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `start_timestamp` | int64 | 否 | 7天前 | 查询开始时间戳（秒） |
| `end_timestamp` | int64 | 否 | 当前时间 | 查询结束时间戳（秒） |

### 响应格式
```json
{
  "success": true,
  "message": "",
  "data": [
    {
      "model_name": "gpt-3.5-turbo",
      "count": 1000,
      "quota": 50000,
      "token_used": 25000,
      "created_at": 1704067200
    }
  ]
}
```

### 响应字段说明
- `model_name`: 模型名称
- `count`: 该模型的总请求次数
- `quota`: 该模型的总消耗额度
- `token_used`: 该模型的总Token使用量
- `created_at`: 数据创建时间戳（按小时聚合）

### 错误响应
```json
{
  "success": false,
  "message": "时间跨度不能超过31天"
}
```

## 🔒 安全考虑

1. **时间范围限制**: 查询时间跨度不超过31天，防止性能问题
2. **数据聚合**: 返回的是按模型和时间聚合的统计数据，无具体用户信息
3. **权限控制**: 接口完全公开，无需任何认证
4. **性能保护**: 通过时间限制和数据聚合避免大数据量查询
