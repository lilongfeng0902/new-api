### 2.3 渠道选择策略详解

**文件位置:** `service/channel_select.go`

**核心函数:** `CacheGetRandomSatisfiedChannel(param *RetryParam)`

**算法流程:**

```go
1️⃣ 如果 TokenGroup == "auto" (自动分组)
   ├─ 获取用户可用的auto分组列表
   │  例如: ["default", "vip", "premium"]
   │
   ├─ 跨分组重试逻辑 (如果启用):
   │  ├─ 每个分组内用完所有优先级后才切换到下一个分组
   │  ├─ 使用 ContextKeyAutoGroupIndex 跟踪当前分组索引
   │  ├─ 使用 ContextKeyAutoGroupRetryIndex 跟踪分组开始时的retry次数
   │  └─ priorityRetry = Retry - startRetryIndex
   │
   │  示例 (2个分组, 每个2个优先级, RetryTimes=3):
   │  ┌──────────────────────────────────────────────┐
   │  │ Retry=0: GroupA, priority=0                  │
   │  │         (startRetryIndex=0, priorityRetry=0) │
   │  │ Retry=1: GroupA, priority=1                  │
   │  │         (startRetryIndex=0, priorityRetry=1) │
   │  │ Retry=2: GroupA用完 → 切换到GroupB           │
   │  │         GroupB, priority=0                   │
   │  │         (startRetryIndex=2, priorityRetry=0) │
   │  │ Retry=3: GroupB, priority=1                  │
   │  │         (startRetryIndex=2, priorityRetry=1) │
   │  └──────────────────────────────────────────────┘
   │
   └─ 遍历 auto 分组列表:
      ├─ 调用 GetRandomSatisfiedChannel(group, model, priorityRetry)
      ├─ 如果 channel == nil: 尝试下一个分组
      └─ 返回选中的渠道

2️⃣ 否则 (固定分组, 如"default"/"vip")
   └─ 直接调用 GetRandomSatisfiedChannel(tokenGroup, model, retry)
```

**渠道缓存结构:**

```go
// 三维映射: Group → Model → Priority → []Channel
channelCache = map[string]map[string]map[int][]*Channel

// 实际示例:
channelCache = {
  "default": {
    "gpt-4": {
      5: [channel#1(weight:100), channel#2(weight:50)],  // 最高优先级
      4: [channel#3(weight:80)],
      3: [channel#4(weight:60)]
    },
    "claude-3-opus": {
      5: [channel#5(weight:100)],
      4: [channel#6(weight:90)]
    }
  },
  "vip": {
    "gpt-4": {
      5: [channel#7(weight:100), channel#8(weight:100)]
    }
  }
}
```

**加权随机选择算法:**

```go
func WeightedRandomSelect(channels []*Channel) *Channel {
    // 1. 计算总权重
    totalWeight := sum(channel.Weight for channel in channels)
    // 例如: channel1(weight:100) + channel2(weight:50) = 150

    // 2. 生成随机数 [0, totalWeight)
    randomWeight := rand.Intn(totalWeight)
    // 例如: randomWeight = 75

    // 3. 按权重累加选择
    currentWeight := 0
    for _, ch := range channels {
        currentWeight += ch.Weight
        if currentWeight > randomWeight {
            return ch  // 找到目标渠道
        }
    }
    // channel1: currentWeight = 100 > 75 ✓ 返回channel1

    return channels[0]  // fallback
}
```

**关键配置项:**

- `common.RetryTimes`: 单个分组内重试次数 (默认3次)
- `channel.Priority`: 渠道优先级 (数字越大优先级越高)
- `channel.Weight`: 渠道权重 (用于同优先级内的负载均衡)
- `token.CrossGroupRetry`: 是否允许跨分组重试

│                                                         │
│ 2️⃣ 计算预扣配额                                         │
│    公式: quota = promptTokens × modelRatio × groupRatio │
│                                                         │
│    特殊情况:                                            │
│    ├─ 免费模型 (FreeModel=true): quota=0, 跳过预扣费   │
│    └─ 按价格计费: quota = modelPrice × QuotaPerUnit    │
│                           × groupRatio                  │
│                                                         │
│ 3️⃣ 检查并扣除配额                                       │
│    ├─ 检查用户配额 >= quota                             │
│    ├─ 检查Token配额 >= quota (如果非unlimited)          │
│    ├─ DecreaseUserQuota(userId, quota)                 │
│    │  └─ Redis HINCRBY user:{userId} Quota -quota     │
│    └─ DecreaseTokenQuota(tokenId, quota)               │
│       └─ Redis HINCRBY token:{tokenId} RemainQuota -quota │
│                                                         │
│ 4️⃣ 记录预扣费                                           │
│    └─ relayInfo.FinalPreConsumedQuota = quota          │
│                                                         │
└─────────────────────────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────┐
│ 【请求中: 实际调用上游Provider】                         │
├─────────────────────────────────────────────────────────┤
│                                                         │
│ 上游Provider返回实际Token数量:                          │
│ {                                                       │
│   "usage": {                                            │
│     "prompt_tokens": 123,                              │
│     "completion_tokens": 456,                          │
│     "total_tokens": 579                                │
│   }                                                     │
│ }                                                       │
│                                                         │
└─────────────────────────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────┐
│ 【请求后: 后补差价阶段】PostConsumeQuota()                │
├─────────────────────────────────────────────────────────┤
│                                                         │
│ 1️⃣ 计算实际配额消耗                                     │
│    公式:                                                │
│    actualQuota = promptTokens × modelRatio × groupRatio│
│               + completionTokens × completionRatio     │
│                 × modelRatio × groupRatio              │
│                                                         │
│    特殊倍率:                                            │
│    ├─ completionRatio: 输出Token倍率 (默认1.0)         │
│    ├─ cacheRatio: 缓存Token倍率 (Claude, 0.1)          │
│    ├─ audioRatio: 音频Token倍率                        │
│    └─ audioCompletionRatio: 音频输出倍率               │
│                                                         │
│ 2️⃣ 计算差价                                             │
│    quotaDelta = actualQuota - preConsumedQuota         │
│                                                         │
│ 3️⃣ 调整配额                                             │
│    if quotaDelta > 0 {  // 实际消耗更多                │
│      // 补扣费                                          │
│      DecreaseUserQuota(userId, quotaDelta)             │
│      DecreaseTokenQuota(tokenId, quotaDelta)           │
│    } else if quotaDelta < 0 {  // 预扣过多             │
│      // 返还配额                                        │
│      IncreaseUserQuota(userId, -quotaDelta)            │
│      IncreaseTokenQuota(tokenId, -quotaDelta)          │
│    }                                                    │
│                                                         │
│ 4️⃣ 更新统计数据                                         │
│    ├─ user.UsedQuota += actualQuota                    │
│    ├─ user.RequestCount += 1                           │
│    └─ channel.UsedQuota += actualQuota                 │
│                                                         │
│ 5️⃣ 配额告警检测 (异步)                                  │
│    checkAndSendQuotaNotify():                          │
│    ├─ remainQuota = userQuota - actualQuota            │
│    ├─ threshold = userSetting.QuotaWarningThreshold    │
│    └─ if remainQuota < threshold:                      │
│       发送通知 (Email/Webhook/Bark/Gotify/SMS)         │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

**配额单位换算:**

```

换算关系:

显示时:
quota / 500,000 = USD金额

例如:

### 2.5 错误重试和Failover机制

**文件位置:** `controller/relay.go`

**重试决策树:**

```go
func shouldRetry(err *types.NewAPIError, retryTimes int) bool {
    // 1. 基础判断
    if err == nil {
        return false  // 无错误，不重试
    }
    if retryTimes <= 0 {
        return false  // 重试次数用完
    }
    if _, ok := c.Get("specific_channel_id"); ok {
        return false  // 指定渠道不重试
    }

    // 2. 错误类型判断
    if types.IsChannelError(err) {
        return true   // 渠道错误，必须重试
    }
    if types.IsSkipRetryError(err) {
        return false  // 明确标记不重试的错误
    }

    // 3. HTTP状态码判断
    switch err.StatusCode {
        case 429:  // Too Many Requests
            return true   // 限流，重试
        case 307:  // Temporary Redirect
            return true   // 重定向，重试
        case 5xx:  // 服务器错误
            if err.StatusCode == 504 || err.StatusCode == 524 {
                return false  // 超时不重试
            }
            return true   // 其他5xx重试
        case 408:  // Request Timeout
            return false  // Azure超时不重试
        case 400, 401, 403, 404:
            return false  // 客户端错误不重试
        case 2xx:
            return false  // 成功不重试
        default:
            return true   // 其他情况重试
    }
}
```

func GetUserCache(userId int) (*UserBase, error) {
    // 1. 先读缓存
    userCache, err := cacheGetUserBase(userId)
    if err == nil {
        return userCache, nil
    }

    // 2. 缓存miss, 读数据库
    user, err := GetUserById(userId, true)
    if err != nil {
        return nil, err
    }

}

// service/user_stats.go

package service

import (
    "github.com/QuantumNous/new-api/dto"
    "github.com/QuantumNous/new-api/model"
    "time"
)

func GetUserStats(userId int) (*dto.UserStats, error) {
    // 1. 获取用户信息
    user, err := model.GetUserById(userId, true)
    if err != nil {
        return nil, err
    }

    // 2. 基础统计
    stats := &dto.UserStats{
        TotalQuota:   user.Quota,
        UsedQuota:    user.UsedQuota,
        RemainQuota:  user.Quota - user.UsedQuota,
        UsageRate:    float64(user.UsedQuota) / float64(user.Quota) * 100,
        RequestCount: user.RequestCount,
    }

    // 3. 查询今日统计
    todayStart := time.Now().Truncate(24 * time.Hour).Unix()
    var todayLogs []model.Log
    model.DB.Where("user_id = ? AND created_at >= ? AND type = ?",
        userId, todayStart, model.LogTypeConsume).Find(&todayLogs)

    for _, log := range todayLogs {
        stats.TodayRequests++
        stats.TodayQuota += log.Quota
    }

    // 4. 查询 Top5 模型
    var modelStats []struct {
        ModelName    string
        RequestCount int
        TotalQuota   int
    }
    model.DB.Raw(`
        SELECT model_name, COUNT(*) as request_count, SUM(quota) as total_quota
        FROM logs
        WHERE user_id = ? AND type = ?
        GROUP BY model_name
        ORDER BY total_quota DESC
        LIMIT 5
    `, userId, model.LogTypeConsume).Scan(&modelStats)

    for _, ms := range modelStats {
        stats.Top5Models = append(stats.Top5Models, dto.ModelUsage{
            ModelName:    ms.ModelName,
            RequestCount: ms.RequestCount,
            Quota:        ms.TotalQuota,
            Percentage:   float64(ms.TotalQuota) / float64(user.UsedQuota) * 100,
        })
    }

    return stats, nil
}

## ⚠️ 五、最佳实践和注意事项

### 5.1 constant包依赖规则 (关键!)

**文件位置:** `constant/README.md`

**核心规则:** constant包必须保持零依赖，只能引用Go标准库！

**❌ 禁止做法:**

```go
// constant/my_const.go
package constant

// ❌ 错误! 不能引用项目其他包
import "github.com/QuantumNous/new-api/model"
import "github.com/QuantumNous/new-api/service"
import "github.com/QuantumNous/new-api/common"

const (
    MyConst = model.SomeValue  // ❌ 循环依赖!
)
```

**✅ 正确做法:**

```go
// constant/my_const.go
package constant

// ✅ 只引用标准库
import "fmt"
import "time"
import "strings"

const (
    MyConst = 123  // ✅ 只定义常量
)

// ============================================

// model/my_model.go
package model

// ✅ 其他包引用 constant 包
import "github.com/QuantumNous/new-api/constant"

func DoSomething() {
    value := constant.MyConst  // ✅ 正确方向
}
```

**原因:**

- constant包是最底层的包，被所有其他包引用
- 如果constant包引用其他项目包，会形成循环依赖
- Go编译器禁止循环依赖，会导致编译失败

**常见错误示例:**

```
编译错误信息:
import cycle not allowed
package github.com/QuantumNous/new-api/constant
    imports github.com/QuantumNous/new-api/model
    imports github.com/QuantumNous/new-api/constant
```

### 5.3 缓存一致性保证

**写操作流程:**

```go
// 方案1: Write-Through (写穿)
func UpdateUser(user *User) error {
    // 1. 先更新数据库
    err := model.DB.Model(&user).Update("quota", newQuota).Error
    if err != nil {
        return err
    }

    // 2. 删除缓存 (下次读取时重新加载)
    model.DeleteUserCache(userId)

    return nil
}

// 方案2: Write-Through + Cache Update
func UpdateUserQuota(userId int, newQuota int) error {
    // 1. 先更新数据库
    err := model.DB.Model(&User{}).
        Where("id = ?", userId).
        Update("quota", newQuota).Error
    if err != nil {
        return err
    }

    // 2. 直接更新缓存
    userCache := model.GetUserCacheWithoutCheck(userId)
    userCache.Quota = newQuota
    model.SetUserCache(userId, userCache)

    return nil
}
```

**读操作流程:**

```go
// Read-Through (读穿)
func GetUserCache(userId int) (*UserBase, error) {
    // 1. 先读缓存
    userCache, err := cacheGetUserBase(userId)
    if err == nil {
        return userCache, nil  // 缓存命中
    }

    // 2. 缓存miss, 读数据库
    user, err := model.GetUserById(userId, true)
    if err != nil {
        return nil, err
    }

    // 3. 写入缓存
    model.SetUserCache(userId, user.ToBaseUser())

    return user.ToBaseUser(), nil
}
```
