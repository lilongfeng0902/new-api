# 阿里云短信告警功能实现说明

## 功能概述

本次实现为NewAPI项目新增了阿里云短信告警通道，用于在用户额度不足时发送短信提醒。该功能与现有的邮件、Webhook、Bark、Gotify等告警通道保持一致的设计模式，支持模块化替换。

## 实现内容

### 1. 数据结构扩展

#### `dto/user_settings.go`
- 新增 `NotifyTypeSMS = "sms"` 通知类型常量
- 在 `UserSetting` 结构体中新增 `SMSPhoneNumber` 字段，用于存储用户短信接收手机号

#### `common/constants.go`
- 新增阿里云短信相关配置变量：
  - `AliyunSMSEndpoint`: 阿里云短信服务端点
  - `AliyunSMSAccessKeyId`: 阿里云AccessKey ID
  - `AliyunSMSAccessKeySecret`: 阿里云AccessKey Secret
  - `AliyunSMSSignName`: 短信签名
  - `AliyunSMSTemplateCode`: 短信模板CODE

### 2. 短信发送实现

#### `common/alisms.go` (新建)
- 实现阿里云短信API调用逻辑
- 支持模板参数传递
- 实现HMAC-SHA1签名算法
- 提供 `SendAliyunSMS()` 和 `SendQuotaWarningSMS()` 函数

### 3. 告警逻辑集成

#### `service/user_notify.go`
- 在 `NotifyUser()` 函数中新增SMS通知类型处理
- 新增 `sendSMSNotify()` 函数，实现短信告警发送逻辑

#### `service/quota.go`
- 在 `checkAndSendQuotaNotify()` 函数中新增SMS内容格式支持
- SMS使用简短文本格式，避免HTML标签

### 4. 配置管理

#### `model/option.go`
- 在 `InitOptionMap()` 中初始化阿里云短信配置项
- 在 `updateOptionMap()` 中添加阿里云短信配置更新逻辑
- 支持通过API接口动态更新配置

#### `controller/user.go`
- 在 `UpdateUserSettingRequest` 结构体中新增 `SMSPhoneNumber` 字段
- 更新通知类型验证逻辑，支持SMS类型
- 在用户设置构建逻辑中添加SMS手机号处理

## 配置说明

### 环境变量配置

在 `.env` 文件中添加以下配置项：

```env
# 阿里云短信配置
ALIYUN_SMS_ENDPOINT=https://dysmsapi.aliyuncs.com
ALIYUN_SMS_ACCESS_KEY_ID=your_access_key_id
ALIYUN_SMS_ACCESS_KEY_SECRET=your_access_key_secret
ALIYUN_SMS_SIGN_NAME=您的短信签名
ALIYUN_SMS_TEMPLATE_CODE=SMS_xxxxxxxxx
```

### API接口配置

管理员可以通过以下API接口更新阿里云短信配置：

```
POST /api/option
{
  "key": "AliyunSMSEndpoint",
  "value": "https://dysmsapi.aliyuncs.com"
}
```

支持的配置项：
- `AliyunSMSEndpoint`: 阿里云短信服务端点
- `AliyunSMSAccessKeyId`: AccessKey ID
- `AliyunSMSAccessKeySecret`: AccessKey Secret
- `AliyunSMSSignName`: 短信签名
- `AliyunSMSTemplateCode`: 短信模板CODE

### 用户设置

用户可以在个人设置中：
1. 选择通知类型为 "sms"
2. 设置接收短信的手机号

#### API接口调用

**接口路径**: `PUT /api/user/setting`

**请求参数**:
```json
{
  "notify_type": "sms",
  "sms_phone_number": "13800000000",
  "quota_warning_threshold": 1000.00
}
```

**响应示例**:
```json
{
  "success": true,
  "message": ""
}
```

#### 参数说明
- `notify_type`: 通知类型，支持 "email", "webhook", "bark", "gotify", "sms"
- `sms_phone_number`: SMS手机号（当notify_type为"sms"时必需）
- `quota_warning_threshold`: 额度预警阈值（单位：分，必须大于0）

#### 验证规则
- 通知类型必须是系统支持的类型之一
- 预警阈值必须大于0
- SMS类型时手机号为必填项

## 短信模板说明

阿里云短信模板需要预先在阿里云控制台创建，模板变量示例：

```
您的额度即将用尽，剩余额度：${quota}，请及时充值。
```

模板参数通过代码中的 `templateParam` 传递：

```go
templateParam := map[string]string{
    "quota": remainingQuota,
}
```

## 使用流程

1. **配置阿里云短信服务**
   - 在阿里云控制台创建AccessKey
   - 创建短信签名和模板
   - 在系统设置中配置相关参数

2. **用户设置**
   - 用户在个人设置中选择SMS通知类型
   - 填写接收短信的手机号

3. **告警触发**
   - 当用户额度低于预警阈值时
   - 系统自动发送短信告警

## 安全考虑

- AccessKey Secret等敏感信息通过API接口获取时会被过滤，不会在选项列表中显示
- 短信发送包含基本的错误处理和日志记录
- 支持SSRF防护（如果配置了相关设置）

## 扩展性

该实现遵循项目现有的告警通道设计模式，如果需要添加其他短信服务提供商（如腾讯云、华为云等），可以：

1. 创建新的短信服务实现文件
2. 在 `common/constants.go` 中添加相应配置
3. 在 `service/user_notify.go` 中添加新的case处理
4. 更新相关配置管理逻辑

## 注意事项

1. 阿里云短信服务需要预先充值，确保账户有足够余额
2. 短信签名和模板需要阿里云审核通过
3. 不同地区的短信服务可能需要调整端点地址
4. 建议在生产环境中启用短信发送频率限制
