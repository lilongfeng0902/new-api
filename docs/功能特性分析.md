# New API vs Higress 功能特性对比分析

> 本文档对比分析 **New API** 与 **Higress**（阿里云 API 网关）两个 AI 网关产品的功能特性，帮助您了解两者的差异和适用场景。

---

### 🧩 New API VS Neolink

| 功能类别 | 功能模块 | 具体功能与说明 | NeoLink |
| :--- | :--- | :--- | :--- |
| **核心接口与兼容** | **统一接口网关** | 将不同厂商（如OpenAI、Anthropic、Google、DeepSeek等）的API统一封装为 **OpenAI兼容格式** 的接口。开发者只需对接一套接口标准。 | 支持 |
| | **多模型支持** | 支持集成**30+**全球AI服务商，包括GPT-4、Claude、Gemini、Midjourney、Suno等文本、图像、音频模型。 | 优先支持，需人工挨个配置 |
| **路由与调度** | **智能路由与负载均衡** | 支持**多通道负载均衡**、**自动故障转移**和**加权分布**，提高可用性。 | 不支持 |
| | **模型映射与重试** | 可将请求的模型名称映射到其他可用模型，并配置请求重试策略，增强稳定性。 | 需要配置插件，无法全局配置 |
| **计费与配额** | **灵活计费体系** | 支持按请求、使用量（如Token）计费，可配置**费率乘数**（倍率），适配不同模型的成本结构。 | 不支持（受限于openmeter）|
| | **额度与配额管理** | 可为用户、用户组设置调用**额度（Quota）** 和**流量限制**。内置完善的限流机制。 | 暂不支持 |
| | **在线充值** | 提供在线充值功能，支持预付费模式。 | 有限支持 |

| | **API调用审计** | 记录API调用日志，用于安全审计和问题排查。 | 有限支持 |
| **运营与监控** | **实时数据看板** | 提供仪表盘，**实时展示**接口调用量、Token消耗、费用、响应时间等关键指标。 | 有限支持 |
| | **用量统计与分析** | 支持按用户、渠道、模型等维度统计用量和成本，辅助运营决策（相关代码如 ）。 | 有限支持 |
| **部署与架构** | **开源自建** | 项目基于**Golang + Gin框架**开发，代码开源（AGPLv3协议），允许用户自行部署和深度定制。 | |
| | **容器化部署** | 提供**Docker Compose**配置文件，支持一键部署，简化环境配置。 | 支持 |
| | **高可用与扩展** | 架构支持多节点部署，通过配置可实现高可用和水平扩展。 | 暂有限支持 |

## 🎯 适用场景推荐

### 选择 New API 的场景

✅ **个人开发者/中小企业**
- 需要快速搭建 AI 服务聚合平台
- 需要计费系统进行商业化运营
- 需要统一接口调用多种 AI 模型
- 需要 Docker/宝塔面板一键部署
- 预算有限，开源自建

✅ **SaaS 运营商**
- 需要多租户 AI 资产管理
- 需要灵活的计费和配额系统
- 需要在线充值和兑换码
- 需要用户级权限控制

✅ **AI 应用开发者**
- 需要协议转换（OpenAI/Claude/Gemini）
- 需要异步任务（图像/音频/视频生成）
- 需要推理优化（思考模式、力度分级）
- 需要快速集成新模型

### 选择 Higress 的场景

✅ **大型企业/团队**
- 已有 Kubernetes 基础设施
- 需要企业级 API 网关
- 需要与阿里云生态集成
- 需要专业的安全防护（WAF、内容安全）
- 需要成熟的监控告警体系

✅ **云原生应用**
- 需要云原生深度集成
- 需要多集群、多云部署
- 需要服务网格（Istio）集成
- 需要可观测性（Observability）

✅ **高并发场景**
- 需要极致性能优化
- 需要软硬一体加速
- 需要七层负载均衡
- 需要企业级流量治理
